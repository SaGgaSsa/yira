# Yira Brand Concepts

Three simplified Material-style directions for the Yira app icon and GitHub README cover.

Open `index.html` in a browser to compare the concepts together.

## Variants

- `Material Filled`: dark rounded app icon with a filled walker silhouette.
- `Material Rounded`: light icon with thicker rounded strokes and simple shapes.
- `Material Symbol`: compact badge mark, closest to a standalone Material symbol.

## Notes

- These SVGs are concept assets only.
- Nothing here is wired into Electron Builder yet.
- If one direction is selected, the production app icon should be exported to the platform formats expected by Electron Builder, such as PNG/ICO/ICNS.
