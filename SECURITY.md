# Security policy

## Supported versions

The latest Yira release is supported for security fixes.

## Report a vulnerability

Report security vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/SaGgaSsa/yira/security/advisories/new). Do not report vulnerabilities in public issues.

Yira runs local shells and commands. Security reports can cover the preload bridge and IPC handlers, renderer access to Node.js, embedded browser tiles, and the Board MCP server. Include the affected version, steps to reproduce, and any relevant impact. Do not include secrets or personal data in the report.
